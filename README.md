# AmazonAdsExpert — Static HTML/CSS/JS

No Node.js, npm, Astro, React, or build step is required.

## Run locally
Double-click `index.html`, or use VS Code Live Server.

## Deploy
Upload the whole folder to any static hosting provider such as Cloudflare Pages, GitHub Pages, Netlify, or similar.

## Domain
After purchasing `amazonadsexpert.com` from GoDaddy, point its DNS records to your chosen hosting provider.

## Edit
- `index.html` — content/sections
- `css/style.css` — design
- `js/script.js` — animations, counters, popup notifications

The site is intentionally static and can later be connected to an API/backend/database without rebuilding the entire project.
